\section intro_sec Introduction

This is the developer documentation of TrueNorth Core, the reference client for
TrueNorth, a CPU-mined fork of Bitcoin Core. Proof of work is RandomNorth, a
RandomX variant, so blocks are found by general-purpose CPUs rather than by
specialised hardware.

The software is a community-driven open source project, released under the MIT
license.

See https://github.com/truenorth-project/truenorth and
https://truenorth-project.github.io/ for further information about the project.
